## Что это

Проект в Claude считает смету на внедрение Битрикс24 по нашему каталогу. Claude подбирает строки каталога под подтверждённые потребности клиента, ставит Количество в книгу из шаблона и выдаёт книгу сметы и обоснование. Часы, ставки и формулы фиксированы; сроки, даты и платежи книга считает сама от даты первого платежа.

КП, договор и спецификацию здесь не делаем — их я собираю по твоей книге.

## Что в комплекте

- `канон\инструкции\Расчёт-смет.md` — инструкция проекта: сверху блок для тебя, ниже моя рабочая инструкция без изменений.
- `канон\katalog-rabot-i-normativy.md` — ставки, нормативы, тексты работ.
- `канон\инструменты\ШАБЛОН_СМЕТА_v202609h.xlsx` — шаблон: каждая книга — его копия.
- `канон\инструменты\parse_smeta.py` — проверка книги перед КП.
- `клиенты\_шаблон\` — заготовка папки клиента.
- `Указатель — в инструкции проекта.txt` — текст для инструкций проекта.

## Настройка — один раз

Основной способ — десктоп-приложение Claude: папки подключаются только в нём.

1. Положи папки «канон» и «клиенты» к себе на компьютер — куда удобно, имена не меняй. Если своя папка «клиенты» уже есть — перенеси в неё только «_шаблон».
2. Создай в Claude проект «Расчёт смет».
3. В инструкции проекта вставь текст из файла «Указатель — в инструкции проекта.txt». В знания проекта ничего загружать не нужно: Claude читает всё из папки «канон».
4. В десктопе подключи к проекту папку «канон» и, если ведёшь клиентов в папке, — «клиенты». Чаты по сметам открывай там же, с подключёнными папками.
5. В Claude должны быть включены создание файлов и выполнение кода — без них он не соберёт книгу.

Без десктопа (браузер, телефон): загрузи в знания проекта четыре файла из «канон» — инструкцию, каталог, шаблон и скрипт, — а в инструкции проекта вставь вместо указателя:

> Проект «Расчёт смет». Инструкция проекта — файл Расчёт-смет.md в знаниях проекта. В начале каждого чата прочитать его целиком и работать по нему; при расхождении с этим текстом прав файл.

Так работает только режим «Чат».

## Как считать

Один чат — одна сделка. В первом сообщении: клиент (бренд), что посчитать, страна, ID сделки в Битрикс24 и дата первого платежа — если известны. Даты нет — Claude спросит; можно поставить условную, она попадёт в «Допущения».

**Режим «Папка»** — подключена «клиенты». Материалы кладёшь в `00-встреча` папки сделки или кидаешь в чат — Claude сохранит их туда же. Нет папки клиента — Claude создаст её из «_шаблон». Книга `СМЕТА_‹Бренд›_vN.xlsx` и `обоснование_vN.md` ложатся в `10-смета`, ключевые числа — в `context.md` клиента.

**Режим «Чат»** — без папки. Материалы прикладываешь в чат, книгу и обоснование Claude отдаёт файлами. В конце — блок «Для карточки сделки»: его переносишь в сделку в Битрикс24. Пересчёт — в том же чате; в новом чате приложи материалы и прошлые книгу и обоснование.

Что давать, по весу: паспорт демо → этикетки → итог звонка или встречи → расшифровка → заявка. Строку сметы даёт подтверждённая потребность клиента, а не пункт заявки. Паспорт демо и этикетки делают мои проекты: есть по сделке — возьми у меня; нет — смета будет предварительной, так и будет написано в первой строке обоснования.

Клиент уже есть у меня — возьми у меня его `context.md` и последние смету с обоснованием: версия продолжится, а не начнётся с v1.

«Сколько примерно стоит» без клиента — прикидка в чате, без файлов.

Пересчёт — новая версия (v2, v3), старые файлы остаются.

## Перед тем как отдать мне

- Проверка `parse_smeta.py` — без ✖. Claude сам пересчитывает формулы книги, запускает проверку и показывает вывод. Если пишет, что пересчитать не может, — открой книгу в Excel, сохрани и верни ему.
- Прочитай в обосновании первую строку (предварительная или финальная), «Не вошло / не подтверждено» и «Допущения».
- Пришли мне книгу, обоснование и вывод проверки — КП и спецификацию соберу по ним.

## Чего не делать

- Руками не править часы каталога, формулы, сроки, даты и суммы платежей: книга считает их сама, вводится только дата первого платежа (F82).
- Не менять инструкцию, каталог и шаблон в своей копии. Нашлась ошибка в формуле — Claude поправит её в книге клиента только с твоего «да» и соберёт блок «Андрею». Правило не подходит — тоже блок «Андрею». Перешли его мне.

## Обновления

Выйдет новая буква шаблона или новая редакция инструкции — пришлю новый комплект. Папку «канон» заменишь целиком, «клиенты» не трогаешь. Указатель в инструкциях проекта менять не нужно. Работаешь без папок — замени четыре файла в знаниях проекта.
